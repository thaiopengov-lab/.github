# Security Policy

ThaiOpenGovLab is a personal initiative committed to ensuring the safety and security of its projects. We appreciate your help in reporting vulnerabilities responsibly.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not report it publicly via GitHub issues. Instead:

1.  **Draft a Detailed Report**: Include a description, impact, and reproduction steps.
2.  **Report via GitHub**: Use the [GitHub Security Advisory](https://github.com/ThaiOpenGovLab/.github/security/advisories/new) feature (if available) or contact the owner directly through the GitHub profile contact information.
3.  **Wait for Confirmation**: We will acknowledge receipt as soon as possible.

## Our Commitment

- We will investigate all security reports.
- We will keep you informed of our progress.
- We will provide credit for responsibly disclosed vulnerabilities once they are resolved.

## Disclosure Policy

We follow a responsible disclosure approach. Please allow a reasonable amount of time to investigate and remediate the issue before making any information public.

Thank you for helping keep this initiative safe.
